# Midnight Heist — السطو الليلي

لعبة تسلل (Stealth) ثلاثية الأبعاد تبني في المتصفح باستخدام **Three.js + Vite + TypeScript**.
الهدف: تسرق **أحافير** (وليس قطعاً أثرية) من متحف ليلاً، تتفادى الحارس بالأصوات، وتعود للمخرج قبل الفجر.

## الحملة (10 مستويات)

- في كل مستوى **قطعة عظم ديناصور إلزامية** (من 10 قطع: جمجمة، فك، أسنان، عنق، أضلاع، عمود فقري، حوض، ذيل، طرف أمامي، طرف خلفي). لا يمكن إتمام المستوى/الخروج بدونها.
- الأحافير (8 أنواع: أمونيت، ثلاثي الفصوص، سرخس، سمكة، ورقة، محارة، حشرة، أثر قدم) تُجمع في الحقيبة بسعة محدودة.
- بعد كل مستوى يذهب اللاعب إلى **المتحف**: قاعة العظام (هيكل ديناصور SVG يُضاء كل قطعة عند تركيبها)، خزانة أحافير منفصلة، ومختبر.
- في المختبر: 3 مراحل (تنظيف → قياس → تسجيل) لكل عينة، ثم كتابة صفحة في **كتاب من تأليف المساعد** (تراكمي).
- بعد دراسة العظم العاشر: `completed = true` وشاشة ختام «الهيكل ينتصب».

## التشغيل

```bash
npm install      # مرة واحدة
npm run dev      # http://127.0.0.1:5173
```

أو انقر مرتين على `تشغيل اللعبة.bat`.

| الأمر | الوظيفة |
| --- | --- |
| `npm run dev` | سيرفر تطوير مع إعادة تحميل فوري |
| `npm run build` | فحص الأنواع + بناء الإنتاج داخل `dist/` |
| `npm run preview` | معاينة نسخة الإنتاج |
| `npm test` | اختبارات المنطق (22 اختبار) |

## التحكم

- **WASD / الأسهم**: حركة
- **Shift**: تسلل (صوت أقل)
- **Space**: ركض (يستهلك القدرة)
- **E**: تفاعل (سرقة / اختباء / الخروج) — اضغط باستمرار
- **R**: رادار (بعد ترقيته من المتجر)
- **Q**: استخدام الأداة
- **C**: تبديل الأداة
- **Esc**: إيقاف مؤقت
- **عجلة الفأرة**: تقريب/تبعيد

## الهيكل

```
src/
  main.ts              # الشاشات، HUD، المتجر، تدفق اللعبة
  engine/
    loop.ts            # حلقة ثابتة 60Hz
    renderer.ts        # WebGL + إعدادات الجودة
    assets.ts          # تحميل GLB/Textures مع تخزين مؤقت
    input.ts           # لوحة مفاتيح + لمس + يد تحكم
    audio.ts           # صوت إجرائي (Web Audio)
    save.ts            # حفظ v2 في localStorage
    i18n.ts            # عربي/إنجليزي + RTL
  game/
    config.ts          # كل قيم الضبط والموازنة
    tuning.ts          # (غير مستخدم حالياً)
    rules.ts           # قواعد نقية + اختبارات (نقود، نجوم، ترقيات)
    levels.ts          # مولّد المستويات
    world.ts           # بناء المشهد والإضاءة
    player.ts          # تحكم اللاعب
    guard.ts           # ذكاء الحارس (دورية/شك/مطاردة/بحث)
    grid.ts            # شبكة المستوى والمسارات
    security.ts        # كاميرات + ليزر + أبواب
    noise.ts           # نظام الضوضاء
    camera.ts / fx.ts / models.ts
  i18n/{en,ar}.json
  styles/main.css
assets/models/*.glb    # نماذج الشخصيات والغنائم
tests/*.test.ts
docs/                  # ملاحظات Manus الأصلية ووثائق النشر
```

## الحالة

- يعمل: التشغيل، الحركة، نظام الضوضاء، الحارس، السرقة، الاختباء، المخرج، الفوز/الخسارة،
  الحفظ، النجوم ومكافأة الشبح، المتجر والترقيات، الأدوات، الجودة، اللغة (عربي RTL)، اللمس.
- أُضيف حديثاً: خريطة مصغّرة حقيقية (جدران/مخرج/لاعب + الغنائم والحراس بعد ترقية الخريطة)،
  أسهم للحراس خارج الشاشة، رادار بمفتاح R مع مؤقت وتهدئة، تلميحات تعليمية للمستوى الأول،
  بطاقة مقدمة المستوى، توهج Bloom على جودة High، فيغنت، ومؤثرات صوتية للاختباء (دقات قلب).
- مُصلَح محلياً: قائمة الإيقاف المؤقت (كانت تجمّد اللعبة)، إعادة بناء الـ HUD كل إطار
  (كانت تكسر الأزرار وتستهلك الأداء)، الخروج من المستوى (كان مستحيلاً)، والخروج من المخبأ.
- قابل للتطوير: موازنة المستويات، أصوات أصلية، نماذج إضافية، خطوط ManusCC0 الأصلية
  (مستبدلة حالياً بخط Cairo).
